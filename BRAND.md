# Generous UI

Generous UI is the final working name for the library.

## Naming

- Product name: **Generous UI**
- npm package: `generous-ui`
- CLI command: `generous-ui`
- Project config: `generous-ui.json`
- Registry manifest: `generous-ui.registry.json`
- CSS prefix: `gui-`
- Design philosophy name: **generous clarity**

## Rationale

The name keeps the philosophy visible without turning it into a trend label. "Generous" means the interface gives users enough size, contrast, affordance, and stability to understand the next move without hunting. "UI" keeps the package plain and searchable.

## Voice

Generous UI should sound clear, direct, and practical. Avoid mystical, luxury, futuristic, or trend-led language. The library is opinionated, but the promise is concrete: clear actions, stable layouts, honest states, and usable source that teams can own.

## Naming Boundaries

Use **Generous UI** for the product and docs. Use `generous-ui` only for code, package names, imports, CLI examples, filenames, and URLs.

Do not introduce secondary names for component groups, themes, or presets unless they describe a real technical boundary. The philosophy is the brand; components should be named by the job they do.
